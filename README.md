# 고민말게냥 🐱

> "후... 잠깐 바람 좀 쐬고 올게요."
> 생각 정리하러 나온 골목, 미뤄둔 **걱정거리들**이 우르르 따라 나왔어요!

산책 나온 뽀짝이를 따라다니는 걱정거리를 물리치고 도토리를 모으는 브라우저 생존 게임입니다.
공격은 자동이니 **이동만 신경 쓰면 돼요.**

### ▶️ [지금 바로 플레이](https://huizhi1667.github.io/gomin-nyang/)

![시작 화면](assets/start_bg.jpg)

## 조작

| 동작 | 키 / 입력 |
|---|---|
| 이동 | 방향키 · `WASD` · 화면 터치/드래그 |
| 공격 | 자동 |
| 일시정지 / 이어하기 | `P` |
| 소리 켜기·끄기 | `M` 또는 화면 우측 상단 버튼 |
| 게임 시작 | 클릭 · `Enter` · `Space` |
| 레벨업 카드 선택 | 클릭 · `1` `2` `3` · `Tab`+`Enter` |

마우스·터치 없이 **키보드만으로도 처음부터 끝까지 플레이할 수 있습니다.**

## 규칙

도토리(🌰)를 모아 레벨업하고, 매 레벨마다 무기나 능력 하나를 고릅니다.
체력이 0이 되면 산책이 끝나요.

**무기** — 최대 5종까지, 각 8레벨

| 무기 | 설명 |
|---|---|
| ⭐ 반짝별 | 가장 가까운 적에게 별을 던집니다 |
| 🌟 빙글별 | 반짝별의 변신형. 쏘는 대신 별이 주위를 회전합니다 |
| 🌸 꽃잎방패 | 몸 주위를 도는 꽃잎이 닿는 적을 계속 때립니다 |
| 💫 반짝물결 | 주기적으로 빛의 물결이 퍼져나갑니다 |
| ⚡ 번개 | 무작위 적을 내리치고 근처로 튕깁니다 |

**능력** — 👟 날쌘발(이동 속도) · ❤️ 튼튼(최대 체력) · 🧲 자석(수집 범위) · 💪 힘(공격력) · ⏱️ 빠른손(공격 속도) · 💖 도토리사랑(획득량)

**회복** — 적이 떨어뜨리는 음식(🍙 일반 3.5% / 엘리트 25% / 보스 100%)으로 체력 +30, 레벨업에서 카드를 고를 때마다 커피 한 모금으로 +15

## 난이도

시간이 지날수록 적의 체력·공격력·속도가 함께 올라갑니다.

- **적 8종이 순차 등장** — 🐛 0초 · 🦠 30초 · 👻 55초 · 🦇 80초 · 🐌 100초 · 👾 130초 · 🤖 170초 · 😈 220초
- **엘리트** (80초 이후, 7% 확률) — 크고 튼튼하며 도토리를 왕창 떨어뜨립니다 👑
- **돌격 웨이브** (35초 이후 30초마다) — 사방을 둘러싸는 링 스폰
- **보스** (60초마다, 240초 이후엔 두 마리) — 방사형 탄막을 뿌립니다 🐲

점수는 `생존 시간 × 10 + 물리친 걱정거리 × 5 + (레벨 − 1) × 100 + 걸은 거리 × 0.02` 로 계산합니다.

## 랭킹

게임이 끝나면 이름을 넣어 기록을 남길 수 있습니다.

- **전체 랭킹** — Firebase Firestore REST API에 저장하고 상위 5위와 내 순위를 보여줍니다
- **로컬 백업** — 서버 저장이 실패해도 브라우저에 상위 10개를 남기고, "다시 시도"로 재전송할 수 있습니다
- 서버 설정이 없으면 자동으로 로컬 랭킹만으로 동작합니다

브라우저에 저장하는 값은 `gomin_muted`(음소거), `gomin_rank`(로컬 랭킹), `gomin_name`(이름)뿐입니다.

## 접근성

- `prefers-reduced-motion`을 켜두면 CSS 애니메이션과 화면 흔들림이 모두 꺼집니다
- 키보드만으로 시작·플레이·레벨업 선택·재시작이 가능합니다
- 레벨업·일시정지·게임오버 화면은 대화상자(`role="dialog"`)로 알리고, 로딩 진행률과 랭킹 결과는 `aria-live`로 읽어줍니다
- 창을 벗어나거나 탭을 전환하면 자동으로 일시정지합니다

## 실행

의존성도, 빌드 과정도 없습니다. `index.html` 한 파일과 `assets/`(55개, 2.3MB)로 끝이에요.

```bash
git clone https://github.com/huizhi1667/gomin-nyang.git
cd gomin-nyang
python3 -m http.server 8000
# http://localhost:8000 접속
```

`file://`로 직접 열어도 게임은 돌아가지만, 브라우저에 따라 랭킹 서버 요청이 막힐 수 있어 로컬 서버를 띄우는 편이 좋습니다.

## 구성

바닐라 JavaScript + Canvas 2D로 만든 단일 파일 게임입니다.

- **렌더링** — 이모지는 오프스크린 캔버스에 한 번만 구워 재사용하고, 배경은 타일로 반복합니다
- **적 충돌** — 96px 격자 공간 분할로 인접 칸만 비교합니다
- **사운드** — 오디오 파일 없이 Web Audio API로 효과음과 BGM을 직접 합성합니다
- **화면 대응** — 세로 화면에서는 시작·엔딩 일러스트를 모바일용으로 교체하고, HUD는 안전 영역(safe area)을 피해 배치합니다
